## How the sites are linked but separate

Linked (identical on every site, generated by `scripts/sync.py`):

- The estate bar across the top, listing the estate and all three businesses, with the current one marked.
- The mark: one ring for the estate, a different centre for each business (hills, house, tree, apple).
- Typography (Cormorant Garamond headings, Inter text), spacing, buttons, cards and photography treatment.
- The "Also on the estate" band near the foot of each business site, pointing to the other two.
- The estate footer, with the shared address and estate office.

Separate (owned by each business):

- Its own domain, name, accent colour and centre of the mark.
- Its own navigation, calls to action, phone numbers and inboxes.
- Its own content and customer journey (book a stay, order logs, buy juice).

The rule: a visitor should always know which business they are dealing with, and should always be one click from the rest of the estate.

## Editing

- Page content lives in each folder's `index.html`.
- Shared colours and layout live in `assets/css/estate.css`. Each business only overrides the tokens in its `[data-brand]` block.
- Shared blocks sit between markers such as `<!-- @footer halecat -->`. Do not edit inside them by hand. Change `scripts/sync.py` and run:

```
python3 scripts/sync.py
```

That also regenerates `vercel.json`.

## Preview locally

```
python3 -m http.server 8000
```

Open http://localhost:8000/estate/ and click through. Links between sites use folder paths, so everything works offline.

## Going live (Vercel)

1. Import this repository as a Vercel project. No build step or framework is needed.
2. Add all four domains (and their `www.` versions) to the project.
3. Point each domain's DNS at Vercel.

`vercel.json` routes each domain to its own folder, and redirects any link to a sister site onto that site's own domain. Preview URLs and unknown hosts land on the estate home.

## Before launch

- Confirm `witherslackestate.co.uk` is the right domain for the estate home (it matches the estate office email). If not, change it in `scripts/sync.py` and re-run.
- Orchards phone: the old site shows both 07760 286785 and 07881 098359. The new site uses 07760 286785.
- The Orchards Wix shop will stop working once the domain moves. Online ordering is currently by email; add a shop (for example Shopify Buy Button or Stripe Payment Links) if direct sales justify it.
- Halecat booking is by phone with Elaine. An availability calendar or booking widget would convert better.
- Photography is taken from the existing sites. Halecat in particular needs interior shots (bedrooms, library, fire, summerhouse).
- Set 301 redirects for important old URLs (for example `/firewood`, `/accommodation-details/`) to the matching section, to protect search rankings.
